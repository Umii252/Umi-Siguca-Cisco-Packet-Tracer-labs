Spanning Tree Protocol (STP) Lab

Overview

A Cisco Packet Tracer lab demonstrating Spanning Tree Protocol (STP) in a redundant Layer 2 network.

Technologies

* Cisco 2960 Switches
* VLAN 10
* IEEE 802.1Q Trunking
* Spanning Tree Protocol (STP)
* IPv4
* ICMP

What I Practiced

* Creating VLAN 10
* Configuring access ports
* Configuring trunk links
* Building a redundant Layer 2 topology
* Understanding STP root bridge election
* Identifying forwarding and blocking ports
* Modifying STP bridge priority
* Configuring SW1 as the root bridge
* Verifying STP operation
* Testing end-to-end connectivity

Verification

Used Cisco IOS commands including:

* show vlan brief
* show interfaces trunk
* show spanning-tree vlan 10
* ping

Result

Successfully configured STP to prevent Layer 2 loops while maintaining connectivity between the end devices.

Packet Tracer File

The .pkt file contains the completed network topology and configuration.
