VLAN & DHCP Lab

Overview

A Cisco Packet Tracer lab demonstrating VLAN segmentation and DHCP configuration for automatic IPv4 address allocation.

Technologies

* Cisco 2911 Router
* Cisco 2960 Switch
* VLANs
* DHCP
* IPv4
* ICMP

What I Practiced

* Creating and configuring VLANs
* Assigning switch ports to VLANs
* Configuring router interfaces
* Configuring DHCP pools
* Assigning IP addresses dynamically to client devices
* Configuring default gateways
* Testing network connectivity
* Troubleshooting VLAN and IP addressing issues

VLANs

* VLAN 10
* VLAN 20

Verification

Used Cisco IOS commands including:

* show vlan brief
* show ip interface brief
* show ip dhcp binding
* show ip dhcp pool
* show running-config
* ping

Packet Tracer File

The .pkt file contains the completed network topology and configuration.
