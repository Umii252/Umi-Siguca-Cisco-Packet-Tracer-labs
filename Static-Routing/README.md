Static Routing Lab

Overview

A Cisco Packet Tracer lab demonstrating static routing between multiple networks using Cisco routers.

Technologies

* Cisco 2911 Routers
* Cisco 2960 Switches
* IPv4
* Static Routing
* /30 WAN subnetting
* ICMP

What I Practiced

* Configuring router interfaces
* Assigning IPv4 addresses
* Creating /30 WAN networks
* Configuring static routes
* Connecting remote networks through multiple routers
* Verifying routing tables
* Troubleshooting IP addressing and routing issues
* Testing end-to-end connectivity

Verification

Used Cisco IOS commands including:

* show ip interface brief
* show ip route
* show running-config
* ping
* traceroute

Packet Tracer File

The .pkt file contains the completed network topology and configuration.
