OSPF Dynamic Routing Lab

Overview

A Cisco Packet Tracer lab demonstrating dynamic routing using OSPF.

Technologies

* Cisco 2911 Routers
* Cisco 2960 Switches
* OSPF
* IPv4
* /30 WAN subnetting
* ICMP

What I Practiced

* Configuring router interfaces
* Assigning IPv4 addresses
* Creating /30 WAN networks
* Configuring OSPF Area 0
* Establishing OSPF neighbor relationships
* Verifying dynamically learned routes
* Testing end-to-end connectivity

Verification

Used Cisco IOS commands including:

* show ip interface brief
* show ip ospf neighbor
* show ip route
* show ip protocols
* ping

Packet Tracer File

The .pkt file contains the completed network topology and configuration.
